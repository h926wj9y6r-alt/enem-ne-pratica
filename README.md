# ENEM na Prática

Página de vendas do ebook de revisão com 700 questões comentadas.

## Publicar no Netlify

Vincule este repositório ao projeto existente no Netlify, usando a branch `main`.

- Base directory: deixe vazio.
- Build command: deixe vazio.
- Publish directory: `.`

A configuração de publicação também está em `netlify.toml`. A página é estática e não precisa instalar dependências.

Os botões de compra direcionam para o checkout da Kiwify. O material pago é entregue pela plataforma e não está neste repositório.
